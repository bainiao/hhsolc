directories:
    hardhat.config.ts: the main cofiguration file, which defines settings like Solidity compiler version,
            network configurations, and plugins, and tasks your project uses.
    contracts: Solidity contracts and test file by using .t.sol extension
    test: typescript integration tests
    ignition: deployment module that describes how your contracts should be deployed.
    scripts: any custom scripts that antumate parts of your workflow. 
            Scripts have full access to Hardhat's runtime and can use plugins,
            connect to network, deploy contracts, and more.

---剩gas
1. 定义error(message), require和revert时，比直接字符串剩gas
2. 减少storage访问次数，节省gas
3. memory修饰数组，一次创建长度的数据，然后赋值，比多次push节省gas
4. calldata参数比memory参数少gas
5. view函数读取storage数据，不修改storage数据，不消耗gas
6. use uncheck on some calculate, 0.8.0+ version check overflow/underflow and revert, but it cost more gas
7. 给合约内数组赋值，可以把数组参数在方法内创建一个memory参数接受数据，然后把这个数据赋值给合约内storage变量
8. 数组比切片省gas
9. 小类型的数组会打包存储，小于bytes32，会省gas
10. 初始化不赋值，比赋默认值省gas
11. require，revert，assert返回error()或error("message"), message小于bytes32省gas
12. deleta 变量返gas
13. 一些不重要的数据可以存在event中，很久以前的event查询慢
