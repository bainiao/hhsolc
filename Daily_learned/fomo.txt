1. contract
    1. erc20 token: exchange usdt and fomo.
    1. create mining pool, mining machines, set interest levels
    2. generate winner machine who wins 57% total consumption, winner acount gets 30%, 
        others in the same pool share 10%, rest 3% is bured
    3. generate random win number: generate a salt off-chain, use it to generate a hash and publish it on chain.
        at the disclosing time, get win number by: uint256(keccak256(abi.encodePacked(block.timestamp, salt))) % 100,
        then calculate proportion of each pool, p1 = pooling machines in pool1 / pooling machines of all the pool,
        p1 + p2 + p3 + ... + pn = 1, pool 1 winning range 0 ~ p1, pool 2 winning range: p1 ~ p1 + p2, pool n winning range: p1 + ... + pn-1 ~ pn
        which range that win number locates winnes.
    4. 0.2% of reward to owner of pool, 0.3% of reward to host, the rest goes to buyers who bought mining machine according to proportion of amount of mining machine they own.

2. backend
    1. record winning event,
    2. record balances of each account.
    3. calculate proportion of mining pools.
